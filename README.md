# PyTorch Practice

My first steps with PyTorch, written as I learned. I started from tensors and the basics, then moved on to neural networks, CNNs, transfer learning, and sequence models like RNN and LSTM.

All notebooks were written in Google Colab. Some use a GPU, so they run best on Colab with a GPU runtime.

## What's inside

| Notebook | Topic |
|---|---|
| `pytorch_1.ipynb` | PyTorch basics |
| `pytorch-2.ipynb` | PyTorch basics |
| `pytorch-3(nn_pipeline).ipynb` | Neural network training pipeline |
| `pytorch-4.ipynb` | Training with PyTorch |
| `pytorch-5(dataset-and-dataset-loader).ipynb` | Dataset and DataLoader |
| `pytorch-7(ANN).ipynb` | Artificial Neural Network (ANN) |
| `pytorch-8(ann_fashion-mnist_gpu).ipynb` | ANN on Fashion-MNIST using GPU |
| `pytorch9-hyperparameter-tuning-ann-fashion-mnist-using-Optuna(gpu).ipynb` | Hyperparameter tuning with Optuna |
| `pytorch-10(CNN-using-pytorch).ipynb` | Convolutional Neural Network (CNN) |
| `pytorch11-transfer-learning-fashion-mnist-cnn(gpu).ipynb` | Transfer learning on Fashion-MNIST |
| `pytorch12-rnn.ipynb` | Recurrent Neural Network (RNN) |
| `pytorch13-lstm-next-word-predictor.ipynb` | LSTM next-word predictor |
